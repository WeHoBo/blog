这是一篇写给读者的使用说明，也是一份给站内 AI 助手的「知识底稿」。如果你在这里找不到想做的事，多半在下面某一节里。

## 这个站是什么

「博观」是一个个人技术博客，域名 `codeup.asia`，由博主一人写作与维护。内容主要是后端、前端、AI 与工程实践类笔记。站点没有广告、没有推荐流，右上角的搜索框和分类页是最快的入口。

技术上它是 Nuxt 3（SSR）+ Spring Boot 3 + 一个独立的 Python RAG 服务，AI 助手能读到站内文章正是靠后者。

## 读文章时能用什么

进入任意一篇文章，正文区之外还有这些能力：

- **左侧目录**：`lg` 以上屏幕显示，列出全文标题。长文读起来吵的话，点目录上方的手柄可以收起，收起后左侧留一条窄轨，随时点开；这个状态会记住，下次打开还是收起。
- **代码块**：带语言徽标；部分代码块有文件名和行号，超长代码可以折叠展开。右上角有复制按钮（含行号开关、自动换行）。一篇文章里并列展示多种写法时用「代码组」标签页切换。
- **数学公式**：支持 `$行内$` 与 `$$行间$$` 两种写法，用 KaTeX 渲染。
- **图片**：点开是大图灯箱，支持多图左右切换、滚轮/双指缩放；正文里的图片会按屏幕宽度自动取合适尺寸。
- **章节锚点**：每个标题右侧有个 `#`，点它能把这一节的链接地址复制出来分享。
- **字数与评论数**：标题下方会显示本文大约多少字、多少条评论。字数按字符统计，英文按字母算，所以英文偏多的文章字数看起来会偏大。
- **文末**：有上一篇/下一篇，以及「相关推荐」（同分类优先，不够时用最新文章补齐）。

## 怎么找内容

**搜索**：顶栏中间的搜索框，或者按 `Ctrl + K`（macOS 是 `Cmd + K`）直接聚焦。输入时会出现历史记录，`↑` `↓` 选、`Enter` 搜索、`Esc` 关闭。

有一点要说清楚：**搜索只匹配标题、摘要、标签名、分类名，不搜正文**。所以「我记得文章里提过某个词」这种情况，搜索可能搜不到——换用分类页或标签页更可靠。

**分类页 / 标签页**：顶栏「分类」「标签」进入。分类是一篇文章归属的唯一大类，标签可以挂多个。

**归档页**：按时间倒序列出全部文章，适合「最近写了什么」。

**发布热力图**：首页左侧分类下面有一个按月切换的日历，颜色越深表示当天发布的文章越多。它统计的是**已发布**文章的发布时间，草稿不计入。

## 外观可以自己调

- **明暗模式**：顶栏右侧的太阳/月亮图标，一键直切，不用进设置。
- **主题色**：调色板面板里的色相滑块，只改色相（0–360），饱和度和明度是固定的，所以怎么拖都不会出现刺眼的荧光色。选择会存在浏览器本地，换设备不同步。
- **壁纸**：支持几种模式（纯色、图片等），在「外观设置」面板里选。

## 评论与互动

文章底部是评论区，**看评论不用登录，发评论需要登录**。未登录时输入框位置会显示「登录后发表评论」。

单条评论最多 500 字。看到不合适的评论可以点举报，博主会在后台处理。

## 登录与个人资料

本站**只支持第三方账号登录**（Gitee / GitHub / 华为账号），没有独立的账号密码注册。登录入口在顶栏右上角。

登录后在「个人中心」（`/profile`）可以改：

- **头像**：上传图片，限 2MB 以内，支持 jpg / png / gif / webp / bmp / avif，前端会先压到 512px 再传。上传完记得点「保存修改」。
- **昵称**
- **个人简介**：最多 200 字，会显示在首页右栏的作者卡片上。

⚠️ **首页右栏那张卡片显示的是「你自己」，不是站长的信息**（前提是你登录了）。没填简介时它会显示「还没写简介，去补一句」，没传头像时显示昵称首字母。只有**未登录的访客**看到的那张卡，才是站长的博主信息。所以「为什么右栏头像和我顶栏的不一样」这个问题，多数情况是因为你登录了——右栏显示的是你自己。

首页顶部的横幅「你好，我是 xxx」是另一回事：那是站点广播，所有访客看到同一份内容，只有管理员能在后台改。

## 站内 AI 助手

右下角的浮动按钮打开 AI 面板。它可以：

- 基于**站内文章**和你上传的文档回答问题，回答里会带来源链接，点标题直接跳到对应文章；
- 帮你找「哪篇文章讲过某个东西」；
- 面板左上角可以拖拽调整大小，尺寸会记住；
- 推荐问题可以点「换一批」，每次换掉一部分而不是整屏刷新。

它有几个明确的边界，知道这些能少走弯路：

1. **它只读站内资料**。没写过的内容它不知道，也不会去网上现查（除非配了联网搜索，那时它会说明「根据网上资料」并给链接）。
2. **它不操作你的账号**。改头像、发文章、删评论这类事它做不到，只会告诉你该去哪一页点哪个按钮。
3. **有额度限制**。每用户分「每分钟 / 每小时 / 每天」三层计数，全站还有一个日预算兜底。管理员的账号不受个人限额限制。
4. **它分得清「没有」和「查不到」**。如果它说「站内资料里没有相关内容」，是真的没写过；如果它说「站内检索暂时不可用」，那是检索服务出故障了，跟站内有没有内容无关——这种情况稍后再试，或者直接告诉博主。

## 给管理员（普通读者可跳过）

登录后有权限的账号，顶栏会出现「后台」入口。主要能力：

- **文章**：Markdown 编辑器带实时预览；可存草稿、立即发布、或指定发布时间（到点自动上线）；支持导入 Markdown 与 Word 文档；可导出。
- **回收站**：删除的文章先进回收站，30 天内可恢复。**彻底删除不可撤销**，只有超级管理员能操作。
- **版本历史**：每篇文章保留最近 30 个版本，可以查看差异并回滚。编辑过程中会自动打快照，不会因为手滑丢内容。
- **分类 / 标签 / 友链 / 评论**：增删改查与评论审核。
- **素材库**：上传的图片进这里统一管理。
- **站点设置**：站名、首页横幅文案、博主名与简介、SEO 标题描述、AI 助手名字/欢迎语/推荐问题池、壁纸。
- **AI 模型与用量**：查看各模型的调用次数和花费、设置限流与全站日预算。**模型增删改、设默认、改预算只有超级管理员能做**（这些操作一改就是全站在用哪个模型、花多少钱）。
- **用户管理**：改角色、重置密码、禁用账号，同样只有超级管理员能进。

发布文章或保存站点设置后，页面缓存会自动失效，不用手动刷新等 20 秒。

## 常见问题

**搜索为什么搜不到正文里的词？**
因为搜索只匹配标题、摘要、标签、分类。正文不参与搜索，这是为了性能。

**AI 说「检索暂时不可用」是什么意思？**
检索服务故障，不是站内没写过。这种情况 AI 不会拿自己的记忆冒充站内资料，所以它会如实说不可用。

**为什么右侧作者卡和顶栏头像不一样？**
右栏是你自己的资料（登录后），顶栏也是你自己——两者都来自你的个人中心。若有出入，多半是个人中心里还没点「保存修改」。访客看到的才是站长的博主信息。

**上传头像失败？**
检查三点：是不是图片格式（不支持 svg/pdf）、是否超过 2MB、是否登录了。头像上传和后台素材库是两个入口，普通账号只能传头像。

**评论发不出去？**
发评论需要登录。看评论不需要。

**一篇文章有两个链接？**
`/post/文章英文标识` 和 `/article/数字ID` 指向同一篇内容，前者是规范地址。分享时优先用 `/post/...` 那种。

**暗色模式在哪切换？**
顶栏右侧的日月图标。主题色与壁纸在调色板/外观设置面板里，两者不在一处。

**文章字数怎么算的？**
去掉代码块、图片、链接语法后按字符数统计，英文按字母计。所以「hello world」会算 10 字。
