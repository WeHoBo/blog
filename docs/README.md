## ✅ 已落地速查（避免重复评估旧建议）

- **阅读体验**：图片灯箱（多图/缩放/手势）、代码块（文件名/行高亮/折叠/换行/复制/**代码组 Tab/语言徽标/行号开关**）、KaTeX 数学公式（**文章页 + 关于页同一链路**）、文章目录（**可收起，状态记忆**）/上下篇/相关推荐/作者卡、暗色模式、**Admonition 提示块、图片网格**
- **信息架构**：`/tags`、`/tag/{slug}`、`/categories`、`/category/{slug}` 独立落地页 + sitemap；文章详情 `/post/{slug}` 与 `/article/{id}` 双路由同一组件
- **编辑器**：CodeMirror 6、版本历史与回滚、回收站、媒体库、定时发布、front matter 导入导出、自动存草稿、拖拽/粘贴上传、**导入 PDF（前端解析：文字转 Markdown + 图片自动传 OSS，2026-11-07）**
- **分类体系**：级联删除、内置「未建档文章」兜底、孤儿分类归一化
- **AI**：悬浮助手（RAG + 自由问答、流式、来源展示）、300s 异步超时、RAG 调用令牌、错误兜底
- **安全**：草稿/私密文章防泄露、JWT fail-fast、操作日志表、上传白名单、OAuth state 校验、CORS 白名单、反序列化白名单、XSS 收敛
- **评论治理**：后台评论列表（按文章/内容筛选、只看被举报）、删除并回填 `comment_count`、前台「举报」（固定四种原因）、后台举报处理（删除/忽略）—— 2026-10-29 新增，含 `sql/comment-report.sql`
- **搜索**：关键词覆盖标题 + 摘要 + 标签名 + 分类名（后端整组 `and(w -> …)` 包住 OR），前端 `<mark>` 高亮 + 搜索历史
- **动效与图标**：路由淡入、主题切换圆形扩散（View Transitions，带 `prefers-reduced-motion` 降级）、顶栏明暗一键直切；顶栏图标统一为内联线条 SVG（`stroke-width:1.6` + `currentColor`）。季节飘落特效（`FestivalEffect`）已移除
- **外观自定义**：主题色相滑块（0–360，只动色相；**饱和 26% / 明度 40% 锁死**，暗色单独提到 52% 保对比，`localStorage` 持久化 + 首屏内联脚本防跳色）、横幅底部四层水波纹（可开关，仅横幅模式）、壁纸四模式、列表/网格布局、文章排序 —— 全部在「外观设置」面板，明暗只在顶栏
- **横幅文案（Banner Title）**：首页「你好，我是 ___」、副标题、头像、SEO 标题/描述全部来自后台「站点设置」的 4 个博主字段（2026-11-07），漏配自动回落原文案
- **运维**：日志落盘滚动、每日备份脚本（`deploy/backup.sh`）、`deploy/` 纳入版本库、systemd 239 兼容
- **性能**：列表列白名单、聚合查询替代 N+1、gzip/brotli、prefetch 过滤、mermaid vendor 化、OSS 图片处理参数（WebP）、**公开页 SWR 缓存（10–300s）+ 阅读数浏览器打点**
