## ✅ 已落地速查（避免重复评估旧建议）

- **阅读体验**：图片灯箱（多图/缩放/手势）、代码块（文件名/行高亮/折叠/换行/复制）、KaTeX 数学公式、文章目录/上下篇/相关推荐/作者卡、暗色模式
- **信息架构**：`/tags`、`/tag/{slug}`、`/categories`、`/category/{slug}` 独立落地页 + sitemap；文章详情 `/post/{slug}` 与 `/article/{id}` 双路由同一组件
- **编辑器**：CodeMirror 6、版本历史与回滚、回收站、媒体库、定时发布、front matter 导入导出、自动存草稿、拖拽/粘贴上传
- **分类体系**：级联删除、内置「未建档文章」兜底、孤儿分类归一化
- **AI**：悬浮助手（RAG + 自由问答、流式、来源展示）、300s 异步超时、RAG 调用令牌、错误兜底
- **安全**：草稿/私密文章防泄露、JWT fail-fast、操作日志表、上传白名单、OAuth state 校验、CORS 白名单、反序列化白名单、XSS 收敛
- **运维**：日志落盘滚动、每日备份脚本（`deploy/backup.sh`）、`deploy/` 纳入版本库、systemd 239 兼容
- **性能**：列表列白名单、聚合查询替代 N+1、gzip/brotli、prefetch 过滤、mermaid vendor 化

## ⏳ 仍待办汇总

> 据各报告「遗留/建议」章节整理，**未逐条复核**；动手前请先在代码里确认现状。

1. 评论审核队列（先审后发）
2. 首页分类筛选仍是页内状态，未改由路由驱动
3. 站点设置 4 项（`siteDesc` / `bloggerName` / `bloggerBio` / `bloggerAvatar`）前台未生效 —— 需先确定首页侧栏展示「登录用户」还是「博主」
4. RSS 订阅
5. 点赞、系列展示、评论楼中楼回复
6. 搜索仅 `LIKE` 标题（不搜正文/标签）
7. RAG 问答历史持久化、博客侧知识库/PDF 入口
8. 关于页不支持数学公式（独立 MarkdownIt 实例）
9. `BusinessException` 仍返回 HTTP 200，其它后台页可能「业务失败误报成功」
10. 未登录桌面访客没有主题入口
11. 静态资源 `gzip_static`、依赖版本锁定 / Dependabot 等工程项

> 完成后请把对应报告移入 `archive/`，并更新本索引；建议清单类文档记得同步顶部「时效状态」块。
